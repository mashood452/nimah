# Gallery headroom correction

Edited with the built-in image generation tool, using each existing gallery photo as the edit target. The gallery CSS, tile layout, image positioning and hover animation are unchanged. Corrected assets are saved as `public/images/gallery/*-v2.webp`; originals remain available.

## Edit prompt used for all seven photos

Use case: identity-preserve. Edit the supplied eyewear editorial photograph to correct insufficient headroom when it is displayed in a responsive website gallery. Preserve exactly the same adult model identity/identities, facial features, hair, expression, eyewear, outfit, pose, scene, color grading, and light. Keep the same overall aspect ratio as the supplied image. Pull the camera back approximately 25–30%, zooming OUT, and seamlessly outpaint/extend the existing realistic background around the original scene, especially ABOVE the heads. Every person's complete head and all hair must be clearly visible, with the TOPMOST HAIR at about 20–22% of the full canvas height, leaving generous natural background above. Preserve horizontal placement relative to each other, including both people in the two-model image. Keep all faces and glasses large enough to read, with natural shoulder and torso proportions. This is a reframing and background extension only: do not redesign the model, do not change glasses, do not change clothing, do not alter the pose. Extend actual sky/architecture/interior logically; do not create a blank band, reflected border, blur padding, inset frame, vignette, typography or watermark. The photo should look like the same photographer took one step back. Must remain robust under a landscape crop and gentle 6% hover zoom, so do NOT place hair close to the top edge.
